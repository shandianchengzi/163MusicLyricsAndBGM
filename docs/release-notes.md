应用内差分更新、固定暗黑主题与界面修复

- 菜单和设置内支持检查更新，改为检查本仓库及完整 BGM 版本号。
- 优先下载匹配当前版本的差分包；必要时下载不含引擎和模型的程序更新包。
- 下载后 SHA256 校验、退出安装、失败回滚并自动重启，保留引擎、模型与用户设置。
- 删除“使用手册”和“问题反馈”，项目主页改为当前 GitHub 仓库。
- 唯一暗黑配色，不再跟随系统或旧配置切换；移除主题选择。
- 修复“更多设置”白色面板与暗黑文字主题混用的问题，辅助窗口同步使用统一色板。
- 伴奏成功保存后自动关闭提取对话框，主窗口显示保存位置；失败或取消时保留提示。

- 已内置 vocal-separate 的运行环境、FFmpeg 和 2stems 模型。
- 完整解压后运行 MusicLyricApp.exe，菜单打开“伴奏提取”即可使用。
- 无需另装 Python/CUDA，无需单独启动 start.exe，无需配置服务地址。
- 支持导入 MP3/WAV/FLAC/AAC/M4A，或下载当前搜索歌曲后提取 WAV 伴奏。
- 默认完全在本机分离，不启动浏览器或 HTTP 服务，不在首次使用时联网下载模型。
- 取消任务、关闭窗口或退出程序时自动停止内置引擎及子进程。

AAC 和 M4A 文件可直接在“导入音频并提取伴奏”中选择，使用默认内置引擎；原版外部服务不接受这两种扩展名。

首次安装：下载 MusicLyricsAndBGM-win-x64.zip 并完整解压，保留 engine 文件夹。
从 v7.3.0-bgm.3 或更早版本升级：下载较小的 MusicLyricsAndBGM-update-win-x64.zip，退出软件后解压覆盖原目录，保留 engine 文件夹。后续点击应用内“检查更新”即可。
运行环境和模型已随包提供，下载体积较大；相比上一版无需另行安装分离工具。
歌曲下载依然受平台权限及直链有效期限制，失败时可导入本地歌曲。

发布前已使用打包后的 Windows 引擎实际分离合成 MP3、AAC（ADTS）和 M4A，验证中文路径、有效 WAV 输出和取消后的进程清理；该测试不代表所有歌曲的分离音质。

引擎基于 jianchang512/vocal-separate v0.0.4（GPL-3.0）。上游源码见附件 vocal-separate-v0.0.4-source.zip；修改后的入口、打包脚本和许可位于包内 engine 目录及本仓库 tools/vocal-engine 目录。第三方组件保留各自许可证。
